# STAHLFRONT

Ego-Shooter im Browser. Team-Deathmatch, Bots füllen die Teams auf, Mehrspieler per Raum-Code mit Video-Chat.

**Spielen:** https://eggermartin202-pixel.github.io/stahlfront/

- Gegen Bots: „Gegen Bots spielen“
- Mit Freunden: einer klickt „Raum erstellen“ und gibt den 4-stelligen Code weiter, die anderen klicken „Raum beitreten“
- Läuft in Chrome, auch auf dem Chromebook. Braucht Tastatur und Maus oder Touchpad.
